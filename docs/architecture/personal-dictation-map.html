Working vertical slice

One owner. Two trusted machines. Four boundaries.

The iPhone handles the interaction that only iOS can perform. Ronin handles the policy and compute that should be shared. Tailscale provides private reachability; an independent Device Credential provides application authentication.

Privacy rule

No retained audio

Idle buffers are discarded. Per-dictation WAV files are transient. Telemetry contains shape and timing—not speech or transcript content.

One dictation, end to end

The control path crosses process boundaries twice on iOS because Apple does not give a third-party keyboard microphone access.

ArmThe Action Button runs the Arm Hex App Intent. The containing app enters a time-bounded warm session and discards idle microphone buffers.
RequestThe custom keyboard writes a Begin command, request ID, text-document identity, and presence heartbeat into the transactional App Group mailbox.
CaptureThe app accepts Begin, opens a private WAV, and routes preallocated real-time tap buffers through a bounded single-producer/single-consumer ring to file I/O off the audio thread.
Stop or cancelStop seals the WAV; Cancel erases the partial artifact and resets the whole request. A stale keyboard heartbeat, disarm, expiry, or capture failure also fails closed.
UploadThe app sends the WAV, Device Credential, and caller-generated request ID over tailnet HTTPS to Ronin. There is no offline queue or silent local fallback.
AuthenticateThe HTTP adapter validates the bounded request and resolves a SHA-256 credential digest to an active, capability-scoped Device Principal.
DeduplicateThe application module claims the request ID in SQLite. A same-audio retry replays its durable result; different audio under the same ID is a conflict.
TranscribeA single fail-fast inference lease protects Parakeet. The pinned runtime/model returns text; the service commits the response before returning it.
DeliverThe app deletes the WAV and publishes the Final Transcript to the App Group mailbox. The keyboard verifies the original document, consumes the transcript, then calls insertText.
RepeatThe warm session remains armed, so the same keyboard can begin another independent request without reopening Hex.

Hosted now

Private Ronin stack

Four pinned containers: Parakeet, the Effect proxy, OpenTelemetry Collector, and Prometheus. The proxy publishes only to 127.0.0.1:8787; Tailscale Serve supplies private HTTPS. The Parakeet port and Collector stay internal.

Not hosted yet

Shared profile and clients

Ronin does not yet host the canonical versioned Transcript Profile, statistics aggregates, or style rewriter. A Windows client and Ronin-backed macOS client are designed but not implemented.

Effect + OpenTelemetry

Latency is a first-class product signal

The server records deeply nested, content-free spans across the real Effect call stack. Metrics separate workload shape from processing speed so longer recordings do not masquerade as regressions.

Failure and security posture

Fail closed

No Ronin, no remote dictation

The iPhone reports the failure. It does not queue speech, switch providers, or pretend a local result exists.

Independent auth

Tailscale is not the credential

Reachability and application authorization are separate. Every installation can be rotated or revoked without disrupting the other devices.

Bounded work

Pressure becomes an error

Audio buffers, request bodies, inference concurrency, transcript size, retained responses, and telemetry dimensions all have explicit limits.

At-most-once

No duplicate cursor insertion

The keyboard consumes the pending transcript before calling iOS. A rare extension death in that gap can lose text, but cannot duplicate it.

Recoverable storage

Online backup, offline restore

Registered SQLite schemas are fingerprinted and integrity checked. Restore stops traffic and forces every restored Device Principal to reauthorize.

Platform constraint

iOS owns the lifecycle

A keyboard cannot launch its app or record directly. The Action Button foreground arm plus warm containing app is the supported personal workflow.

What to work on next

Priorities preserve the working slice first, then move shared product meaning to Ronin, then add clients and higher-level features.

Now

Finish the physical acceptance gate

Repeat multiple real keyboard insertions in one arm, move between text fields, exercise cancel during every phase, and record stop-to-insert latency, battery, thermal, and memory baselines.

Now

Harden real-device audio lifecycle

Measure route changes, interruptions, iOS process suspension, Bluetooth input, and device-sized audio callbacks. Keep regression tests tied to observed phone behavior.

Next

Make Ronin own the Transcript Profile

Add a versioned profile repository, ETags and If-Match, immutable per-dictation snapshots, and the inherited deterministic Hex transform pipeline. This is the settings-sharing seam.

Next

Connect macOS and build Windows

Give each installation its own Device Principal. Start Windows with WASAPI capture, a global toggle hotkey, Tailscale HTTPS, DPAPI credential storage, and clipboard-preserving insertion.

Then

Set latency budgets from evidence

Turn the physical baseline into minimum sample counts, p50/p95/p99 regression thresholds, dashboards, and alerts. Investigate the slowest recorded span rather than guessing.

Later

Statistics and transcript styles

Add content-free aggregate WPM and word counts exactly once per Dictation. Experiment with normal, casual, and professional styles behind a bounded, isolated rewriter with a deterministic fallback.
